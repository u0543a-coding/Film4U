Demo Auth (client-only)
=======================
Files:
  - register.html
  - login.html
  - index.html
  - css/style.css
  - js/auth.js

Hướng dẫn:
  1. Giải nén project.
  2. Mở register.html để tạo user, sau đó login.html để đăng nhập.
  3. Dữ liệu users được lưu trong localStorage; session lưu trong sessionStorage.

Gợi ý nâng cấp: thêm hash password, Bootstrap toasts, validate mạnh hơn.
